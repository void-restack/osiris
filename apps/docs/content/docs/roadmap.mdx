**How to Participate:**
- Pick an RFP that interests you
- Build your solution using the Osiris SDK
- Share your project with the community for feedback and recognition

**Ready to build?** Start with the [SDK documentation](/docs/sdk) or join our [Discord](https://discord.gg/osiris) to connect with other builders.
