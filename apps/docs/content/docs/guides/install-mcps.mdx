# MCP Usage Guide

This guide explains how to use the various Model Control Protocols (MCPs) available in the Osiris ecosystem.

## Getting Started

### 1. Authentication Setup

First, you need to authenticate with the Osiris platform:

```bash
# Login to existing account
npx @osiris-ai/cli login

# Or register a new account
npx @osiris-ai/cli register
```

### 2. Connect Authentication to Hub

Once authenticated, connect your authentication to the hub:

```bash
npx @osiris-ai/cli connect-auth
```

### 3. Connect Authentication to MCP

To use a specific MCP, you need to connect your authentication to that MCP:

```bash
npx @osiris-ai/cli connect-mcp-auth
```

When running this command, you'll need to provide:
- **Package ID**: The unique identifier for the MCP
- **Redirect URI**: The callback URL for authentication
- **Account Selection**: Choose which account to connect

## Troubleshooting

### Common Issues

1. **Authentication Failed**: Make sure you're logged in with `npx @osiris-ai/cli login`
2. **Connection Issues**: Verify your internet connection and try `npx @osiris-ai/cli connect-auth` again
3. **MCP Not Found**: Double-check the package ID matches exactly from the table above
4. **Permission Denied**: Ensure you have the necessary permissions for the scopes required by the MCP

### Getting Help

If you encounter issues:
1. Check your authentication status
2. Verify the package ID and redirect URI
3. Ensure all required scopes are granted
4. Contact support at osiris@fetcch.xyz
